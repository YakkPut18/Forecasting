# Forecast-Backpropagration-HEXA-stock

## Time Series Forecasting Menggunakan Jaringan Saraf Tiruan (JST)
Repository ini berisi implementasi peramalan data runtun waktu (time series forecasting) menggunakan Jaringan Saraf Tiruan (JST) dengan pendekatan Multi Layer Perceptron (MLP). Proyek ini bertujuan untuk membangun model prediksi yang mampu menangkap pola historis data secara non-linear melalui proses preprocessing yang sistematis dan pemilihan hyperparameter yang optimal.

Notebook utama dalam repository ini adalah:

Forecasting_Project_JST_Kelompok_5.ipynb

yang berisi seluruh tahapan analisis mulai dari eksplorasi data hingga evaluasi model.
